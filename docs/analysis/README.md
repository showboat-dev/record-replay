## 与现状的主要差异（阅读时注意）

v0.1 草案写于实现之前，以下内容后来被真实数据/需求推翻或调整：

- **AI 兜底默认关闭且未接真实模型**：先用确定性 L1/L2 + 人工重录；AI 接口已就绪，等内网端点；
- **多标签页/原生对话框/下载/上传/组合键**后来才补（v0.2），草案未覆盖；
- **参数化**从"录制时自动参数化"改为"录制后规则召回 + 用户确认"（Phase 1），AI 裁决留 Phase 2；
- **公网 10 站语料库**实测 6 站全绿（66.7%），成为判断"哪些失败值得修"的基线；
- 录制器改为**非滚动截图**、步骤后处理合并（草案未考虑这些观感问题）。
